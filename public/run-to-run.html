Program Overview

방학 첫날부터 마지막 날까지, 끝까지 함께합니다.

런투런은 단기 특강도, 강의도 아닙니다. 방학 한 달, 매일의 흐름을 만드는 세 개의 축입니다.

All-in-One Routine

통합사회2 전 5단원에 대해, 매일 개념 재구성 + 문제 풀이가 함께 도는 학습 루틴을 설계합니다. 한 단원도 놓치지 않고 밸런스를 유지합니다.

페이스 메이커 Pace Maker

단기 특강이 아닙니다. 방학 첫날부터 마지막 날까지, 주차별 최적화된 로드맵을 제공하여 중단 없이 완주할 수 있도록 페이스를 잡아드립니다.

무제한 문제 훈련

상황별 · 난이도별 문제를 필요한 만큼 제공합니다. 부족해서 못 푸는 일 없이, 학생의 진도와 실력에 맞춰 실전 감각을 매일 유지합니다.

Online / Daily Routine

"매일의 루틴이 흐름을 만듭니다."

스스로 꺼내 정리하는 개념 재구성, 실전 감각을 유지하는 문제 풀이 — 매일 이 두 축을 돌립니다.

Concept Rebuild

개념 재구성

  • 단원 학습 직후, 노트를 덮고 개념을 스스로 다시 꺼냅니다.
  • 기억이 흐린 부분이 즉시 드러나 그 자리에서 보완합니다.
"혼자 다시 꺼내는 훈련"이 시험장 실력을 만듭니다. 강의로 들은 개념은 하루면 흐려지지만, 스스로 재구성한 개념은 남습니다.
Daily Drill

문제 풀이

  • 매일 새 문제 세트로 실전 감각을 유지합니다.
  • 학생의 진도·실력에 맞춰 필요한 유형이 매일 도착합니다.
"하루 30분이라도 매일 문제를 마주하는 습관이 개학 후에도 흐름을 유지시켜 줍니다."
무한 제공 상황별 · 난이도별 문제를 필요한 만큼 제공합니다. 부족해서 못 푸는 일은 없습니다.

FAQ

자주 묻는 질문

썸머핫습에 참여하고 있으면 별도 결제 없이 되나요?

네. 고1 썸머핫습 재원생은 별도 결제 없이 프리패스로 참여합니다. 신청서만 접수해주시면 됩니다.

단과 재원생인데 참여 가능한가요?

가능합니다. 단과 재원생은 80,000원으로 방학 1개월 전체 루틴 관리에 참여할 수 있습니다.

강의를 듣는 프로그램인가요?

아닙니다. 런투런은 강의가 아닌 루틴 관리 프로그램입니다. 매일 문제 풀이를 스스로 진행하고, 이를 매주 체크합니다.

문제가 부족하지 않을까요?

상황별·난이도별 문제를 무한 제공합니다. 학생의 진도와 실력에 맞춰 필요한 만큼 매일 새 문제로 훈련할 수 있습니다.

결석하면 어떻게 되나요?

다음 등원 시 밀린 루틴을 그날 안에 잡아드립니다.
